# Competition Management

Winforms Application.

## Tech stack

- C# / .NET
- Windows Forms
- Target framework: v4.6.1

## Contents

- Forms: AddPlayerForm, AddTeamForm, DeletePlayerForm, MainForm
- Classes: Competition, Player, ShowPlayersOfATeam, Team, VerificationEnter

## How to run

Open `CompetitionManagement.sln` in Visual Studio (Windows) and press F5.
